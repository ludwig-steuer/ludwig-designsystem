# Ludwig Marketing — UI Kit

The public ludwig.de website. Voice and visuals must feel **calm, confident, professional** — never startup-y.

## Sections
- **Header** — logo + nav + sign-in
- **Hero** — full-bleed primary block, serif Display, single CTA
- **Wie Ludwig arbeitet** — 3-step explanation
- **Vergleich** — manuelle Buchhaltung vs Ludwig
- **Sicherheit & Datenschutz** — DSGVO, Server in Deutschland (key trust signal)
- **Preis** — single tier, transparent
- **Footer**

## Components
`MarketingHeader.jsx`, `Hero.jsx`, `HowItWorks.jsx`, `Compare.jsx`, `Trust.jsx`, `Pricing.jsx`, `MarketingFooter.jsx`
